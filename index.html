--text-2xl · Righteous · 2.25rem
Every shiny thing, catalogued
--text-xl · Righteous · 1.5rem
Section heads and man pages
IBM Plex Mono · --text-base · 1rem · capped at --measure (68ch)

Body copy runs in IBM Plex Mono at 400. It sets dense, stays readable at small sizes, and never pretends to be a prose face. Long passages keep a 68ch measure — full-width layout does not mean full-width reading.

Weight 500 carries prompts, labels, and emphasis. Weight 600 is for panel titles and anything that must be found fast. Nothing above 600 ships.

## 03

— Layout

full width is the default · text keeps its measure

Full width is the default. Text keeps its measure. Header, footer, rules, and grids run edge to edge; running text stops at 68ch. There is no center column toggle — this is the layout language.

this band is full-bleed — it ends at the viewport, minus --pad (clamp(24px, 6vw, 96px))
this column is --measure (68ch) — prose stops here no matter how wide the window gets. Resize the window: the band follows, the measure does not.

spacing

--space-1 … --space-9, 4px base. Bars to scale.

page

--pad — fluid page padding, clamp(24px, 6vw, 96px). Every full-width section uses it for side gutters.

--page-max — 1600px. On viewports ≥ 1800px the content of the header, hero, sections, and footer centers at this ceiling — one shared geometry. The hairlines never do.

radius

--radius: 2px. One step, applied to panels, inputs, buttons, chips. Nothing rounder ships.

grids

repeat(auto-fit, minmax(260px, 1fr)) with 1px gaps painted by --hairline. Panels reflow edge to edge on resize — no breakpoints, no max-width column.

## 06

— Hard rules

8 rules · 0 exceptions
01

no gradients, ever

Not a style choice, a constraint. Flat color carries the palette; if a design needs a gradient, the design is wrong.

02

shine is the only accent

If everything shines, nothing does. One accent, spent carefully — prompts, links, the one primary action.

03

dark is home, light is a guest

Dark is the default theme and the one that gets designed first. Light is fully supported, never the default.

04

full width; text keeps its measure

Chrome and grids run edge to edge. Running text stops at 68ch. Both halves are the rule.

05

never re-derive tokens

Import them. tokens.json is the source of truth; everything else is generated from it. Hand-copied hex is a bug.

06

Righteous for voice, IBM Plex Mono for facts

Headlines and section heads speak in Righteous. Body, UI, and code explain in IBM Plex Mono. No third font.

07

Righteous never below 20px

Small Righteous loses its personality. It sets heroes, section names, and the wordmark only — section numbers, tags, and meta are facts, set in IBM Plex Mono 500.

08

nothing under 13px

--text-sm is 14px and --text-base is 16px. Tags, meta, and captions are not exempt — 13px is the floor, everywhere.
